# Exercise Recognition Using Deep Learning

## Project Overview
This project uses computer vision and deep learning to recognize human exercises from video data. It extracts human body landmarks and joint angles using MediaPipe and OpenCV, then trains deep learning models to classify exercise movements.

## Features
- Extracts frames and body landmarks from exercise videos.
- Calculates body joint coordinates and angles.
- Creates sequential features for exercise recognition.
- Trains and evaluates BiLSTM and Transformer models.
- Compares model accuracy and confusion matrices.
- Saves trained models for future use.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy and Pandas
- TensorFlow and Keras
- Scikit-learn

Install the required libraries:

```bash
pip install opencv-python mediapipe numpy pandas tensorflow scikit-learn matplotlib seaborn
```

## How to Run
1. Clone or download this repository.
2. Open `final_capstone.ipynb` in Google Colab or Jupyter Notebook.
3. Upload or configure the exercise video dataset.
4. Run the notebook cells in order.
5. Train the models and compare their evaluation results.

## Models
- **BiLSTM:** Learns movement patterns across video frames.
- **Transformer:** Uses attention mechanisms to analyze sequential body movement features.

The notebook also contains an experimental Vision Transformer (ViT) implementation for image-based exercise classification.

## Output
The project generates model accuracy comparisons, confusion matrices, training performance plots, and saved model files.
